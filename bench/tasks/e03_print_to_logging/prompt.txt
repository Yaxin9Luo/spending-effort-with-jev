backup/sync.py still uses print() for everything. Switch it over to the logging module with a module-level `logger = logging.getLogger(__name__)`. Levels: the "source directory not found" message is an error, "skipping subdirectory" is a warning, "up to date" is debug, and "copied ..." / "done ..." are info. Drop the "ERROR: " / "WARNING: " prefixes from the message text since the level covers that now. Don't set up handlers or call basicConfig in the module, the caller configures logging. Behaviour otherwise stays the same.
